# Image Role Resolver

Resolve operational image roles before external routing. Use provenance and current explicit instructions, not visual resemblance or attachment recency.

```text
PROTECTED_CANONICAL > EDIT_TARGET > PREVIEW_SHOT_REFERENCE
> ACCEPTED_CONTINUITY > EXPLICIT_EXTERNAL_ROLE > ORIGINAL_PROMPT_REFERENCE
```

## Binding rules

Protected canonical and approved calibration inputs remain subject-owned evidence. Never demote them to arbitrary external roles or edit them through an ordinary image task.

'Change this image's background' binds that usable image as EDIT_TARGET. Freeze one exact edit base and an edit contract naming changed and preserved scopes. Do not reinterpret it as pose or composition reference. Multiple unresolved bases block execution.

A selected preview board/cell is PREVIEW_SHOT_REFERENCE: camera, pose, crop and spatial geometry only. A deterministic selected-cell crop is evidence preparation, not a final image. Only an explicit request to edit preview pixels makes it an EDIT_TARGET; preview provenance remains non-final.

Accepted clean-master provenance is required for ACCEPTED_CONTINUITY. When that image becomes an explicit edit base, EDIT_TARGET wins operationally without changing its authority. Failed or unverified generations never enter continuity because they look similar.

Explicit external roles outrank conservative fallback for the same image. Fallback still needs a safely resolved non-identity scope. Record primary role, source provenance, allowed/denied influence, and separately authorized secondary roles.

## Availability and delivery-only edits

The exact image must be usable in the active execution context; filenames and opaque IDs alone do not establish it. Missing bases and selected previews have distinct blocked codes.

Prefer the original accepted clean master for actual edits or watermark re-derivation. A task explicitly limited to a supplied delivery copy can produce another delivery derivative, but stays outside final-master/continuity promotion. The packet helper for clean-master generation deliberately refuses a delivery-derivative edit base.
